# 07 · 后端：核心子系统

## 1. Agent 与工具（`internal/agent`）

- 主 Agent 名 `"main"`（`agent.go`）；系统提示词来自 `~/.licode/system-prompt.md` + `md/*.md` 附加。
- 工具注册表 `Registry`：`RegisterDefaultTools(r, shellConfig)` 注册内置工具，再合并 `ExternalTools`（热加载外部命令）、插件工具、技能（`skill_*`）、MCP 工具、搜索工具（`RegisterSearchTools`）。
- 工具权限（`settings.go` → `ag.Permissions`）：`tool_rules`（`allow|ask|deny`）+ `ask_tools`/`deny_tools` 兼容数组；`auto_allow=true` 时风险工具直接放行。

### 内置工具清单（`internal/agent/tools.go`）
| 工具 | 用途 |
| --- | --- |
| `Read` | 读文件 |
| `Write` | 写文件（覆盖） |
| `Edit` | 精确文本替换（old/new/all） |
| `ListDirectory` | 列目录 |
| `Grep` | 内容搜索 |
| `Glob` | 路径模式匹配 |
| `Shell` | 执行 shell（可用沙箱 Docker） |
| `Delete` | 删除 |
| `Move` | 移动/重命名 |
| `WebSearch` | 多引擎搜索 + 本地库 |
| `WebFetch` | 抓取单页全文并收录本地库 |

另外：`skill_<name>`（技能）、`plugin_<name>`（WASM 插件）、MCP 工具、`Dispatch`（子代理）、外部热加载工具（`~/.licode/tools`）。

## 2. 子代理 DAG（`internal/agent/subagent.go`）

- 内置子代理：`explorer`（探索代码）、`builder`（实施+验证）、`planner`（计划，不写码）。
- 主 Agent 用 `Dispatch` 工具提交任务数组，`depends_on` 形成 DAG：
  - 同一层**并行**（goroutine）；
  - 依赖完成后才执行；
  - **环检测**（环 → 报错）；
  - 全部完成由主 Agent 汇总。
- 开关：设置 `subagents`（默认 true）、启动 `--no-subagents` 禁用。
- 自定义子代理：`~/.licode/agents/*.md`（frontmatter name/description/tools + 正文为 System Prompt）。

## 3. 会话（`internal/session`）

- 每个 WS 连接创建**全新** `manager`（`NewManager(dir, false)`，**不加载历史**）→ 前端刷新后会话列表为空、切换会话**不回放消息**（后端没有按 id 拉历史的 API）。
- 会话数据实时落盘 `~/.licode/sessions/<id>.json`（`SaveAll`）。
- `session_branch`（index）把历史复制为新会话。
- `sessions` 事件只带 `{id,title,count}`。

## 4. WASM 插件（`internal/plugin`，`internal/web/templates/../docs/plugins.md`）

- 运行时：wazero（纯 Go、沙箱、热加载）。
- 目录：`~/.licode/plugins/<名>/`（用户级）、`.licode/plugins/<名>/`（项目级）、`.opencode/plugins/<名>/`（兼容）。
- 每种插件：`<名>.wasm` + `<名>.json` 清单（name/description/schema）→ 注册为工具 `plugin_<名>`。
- 两种形态：
  - **CLI 模式**（推荐，标准 Go `GOOS=wasip1 GOARCH=wasm`）：入参 `os.Args[1]`（JSON），结果写 stdout；文件系统只读访问工作目录、拒绝绝对路径。
  - **reactor 模式**（TinyGo）：导出 `allocate/execute/_initialize`；宿主注入 `log/http_get/file_read`。
- 生命周期：启动扫描 + `fsnotify` 监听 `.wasm/.json` 变化 → 热加载/卸载。
- 插件崩溃不影响主进程（沙箱隔离）。

## 5. 联网搜索（`internal/search`）

- 三引擎：`bing`、`baidu`、`duckduckgo`（meta 抓取标题/URL/摘要）。
- 本地索引：`~/.licode/search/index.json`（倒排索引：词元→docId→词频），`OpenStore` 单例共享（Agent 工具与 REST `/api` 用同一份）。
- `Service`：`Search(ctx,q,engines,enableMeta,local,max)` → 聚合+排序；`Fetch(ctx,url)` 抓取可读正文（HTML 清洗，`internal/search/html.go`）；`Save(ctx,url)` 抓取并收录。
- 搜索需要**出网**访问搜索引擎；本地库可离线检索。

## 6. 代码审计（`internal/audit`）

- 流程：`Start`（后台任务）→ 静态规则扫描（`rules.go`）+ LLM 分析（`llm.go`，选文件交给 LLM）→ `Report`（含 `Issues`，每条有 id/file/line/severity/category/description/suggestion）。
- 一键修复：`Preview` 生成每文件 diff → `Fix` 应用（写 `<文件>.bak` 备份 + 记录 backup_path/patch）。
- 完成后 `hub.Broadcast(EvtAuditLog)`（content 是 JSON 字符串摘要）→ 前端 toast + 刷新。
- 配置：`audit_enabled`、`audit_auto_fix`、`audit_scan_dirs`、`audit_exclude`（正则列表）。

## 7. 语义缓存（`internal/ai/cache.go`）

- `cache_enabled` + `cache_ttl`：问题-结果缓存，命中直接返回跳过 LLM 调用；`CacheDecorator` 包在 client 外；数据在 `~/.licode/cache`。

## 8. 轻量 RAG（`internal/rag`）

- `rag_enabled` + `rag_source`（目录，默认工作目录）+ `rag_top_files`（默认 5）。
- 对源码目录建索引，查询取 top-N 片段注入上下文（`internal/rag/rag.go`）。

## 9. MCP（`internal/agent/mcp.go`）

- `mcp_servers`：stdio 进程（`command` + `args`）；也可 `url`（SSE 型）。启动 Agent 时逐个拉起并注册其工具。

## 10. Skills（`internal/agent/skills.go`）

- `~/.licode/skills/*.md`：frontmatter `name`/`description` + 正文指令 → 注册 `skill_<name>` 工具，LLM 按 description 决定何时调用。

## 11. 外部命令工具热加载（`internal/agent/toolswatch.go`）

- 监听 `~/.licode/tools`：目录下可执行脚本/命令以文件名为工具名注册进当前 Agent（增删改实时生效）。

## 12. 敏感信息脱敏（`internal/agent/redact.go`）

- `redact_secrets=true`：工具输出中疑似密钥/token 会被打码再回填给 LLM。

## 13. 流式与压缩

- `streaming=true` 时按 token 增量发 `delta`；否则整段文本一次 `delta`。
- `max_iterations` 限制工具调用轮数；`compaction=true` 上下文超限时用 LLM 压缩历史。
- `max_ctx_tokens` 上下文保护阈值（0=关闭）；`retry_max`/`tool_auto_retry`+`tool_retry_max` 控制重试。
