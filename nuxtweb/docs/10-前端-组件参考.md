# 10 · 前端：组件参考

> 15 个组件 + 2 页面。全部组件用 `import { Xxx } from 'fuxsto-design'` 显式引入（**Nuxt 不会自动注册 node_modules 组件**，漏 import 会得到 `Failed to resolve component` 裸元素）。图标来自 `lucide-vue-next`（`<Button :icon="X">`）。

## 页面

### `pages/index.vue` — 主界面
- 挂载时：`initTheme()` → `GET /api/auth`：
  - 后端不可达（异常）→ 照常渲染，靠 `ConnectionBanner` + WS 自动重连提示；
  - `enabled=false` → 直接 `connect()`；
  - `enabled=true` → `GET /api/version`，200 → `connect()`，401 → `navigateTo('/login')`。
- 布局：`<SidebarNav/> <main>(ConnectionBanner + TopBar + ChatArea)</main> <RightPanel/> <SettingsDialog/>`。

### `pages/login.vue` — 登录页
- 用户名**预填 `licode`**；`POST /signin` → `{ok}` → `navigateTo('/')`；失败红色错误框。
- 挂载时若 `auth.enabled=false` 直接回首页。

## 布局组件

### `TopBar.vue`
- 品牌（Bot 图标 + licode）、模型徽标（`settings.model`）、厂商下拉（`settings.providers` → 切换 = `saveSettings` 切 provider + 镜像顶层）。
- 快捷按钮：信息/文件/审计（`state.rightTab` 切换）、主题（Sun/Moon）、设置（打开 SettingsDialog）、面板开关（PanelRight）。
- 全按钮带 `title`（也用于自动化测试定位）。

### `SidebarNav.vue`
- 「新对话」→ `newSession()`；会话列表（切换/重命名/删除，hover 显示操作图标）。
- 重命名态：**外层 `@click.stop`** 阻止点击输入框误触发「切换会话」。
- 底部连接状态点（已连接/连接中/已断开）。

### `RightPanel.vue`
- Tabs：信息 / 文件 / 搜索 / 审计（pill 变体）；`state.rightTab` 驱动 `v-if` 渲染对应面板；X 关闭。
- 收起时宽度 0（过渡动画）。

### `ConnectionBanner.vue`
- `state.wsStatus==='disconnected'` 且持续 **>3s** 才显示：琥珀色横幅 + 后端地址 + 重连按钮。

## 聊天

### `ChatArea.vue`
- 滚动容器：监听 scroll 判断是否吸底（距底 <80px），新消息时自动滚到底。
- Hero 空状态：Bot 图标 + 标题 + 4 个建议 Chip（点击直接 `sendMessage`）。
- 消息列表 `MessageItem`；运行中显示状态行（Loader2 + statusText）。
- 事件委托：点击 `.md-copy` 复制代码。
- 底部渲染 `<AskBar v-if="state.ask"/>` + `<ChatInput/>`。

### `MessageItem.vue`
- 用户：右对齐深色气泡（`whitespace-pre-wrap`，拼接 text 块）。
- 助手：AI 头像 + 内容：text 块 `v-html="renderMarkdown(text)"`（`.md-body`），tool 块 → `<ToolBlock>`。

### `ToolBlock.vue`
- 可折叠（chevron 旋转）；头部：Wrench 图标 + 工具名 + 状态（`Loader2` 执行中 / `Check` 完成）。
- 展开：参数（`prettyArgs`）+ 输出（等宽、max-h 滚动）。

### `AskBar.vue`
- 工具权限条（琥珀色）：`ShieldAlert` + 「工具 `<name>` 请求执行」+ 参数折叠 + 三按钮（拒绝=outline danger / 始终允许=outline / 允许=primary）。
- 参数预览 `prettyArgs`。

### `ChatInput.vue`
- 自适应 textarea（`autoGrow` 限高 192px）；Enter 发送 / Shift+Enter 换行；**`e.isComposing` 防中文输入法误发**。
- 按钮：分支（GitBranch → 确认 → `branchSession`）、清空（Eraser → 确认 → 发 `/clear`）、busy 时「停止」否则「发送」（`disabled=!input.trim()`）。

## 右侧面板

### `InfoPanel.vue`
- stats 展示：消息数、上下文 `context_tokens/context_max` + `Progress`（`context_pct>85` 警告色）、输入/输出 tokens、缓存命中 `cache_hit_rate%/usage_cached`、厂商/模型（`stats||settings` 兜底）、始终允许 chips。
- 版本（`GET /api/version`）、备份导出（fetch blob→a.click）/导入（原生 POST File）、联系链接（GitHub/Gitee/B站）。

### `FilesPanel.vue`
- 工具栏：路径 Input（回车浏览）+ 浏览 + 工作目录(Home) + 刷新；新文件/新文件夹（内联名称输入）；上传（多选，`dir=当前 path`）。
- 面包屑（Windows 路径按 `/` 归一处理）+ 「上级」（`lastIndexOf('/')` 取父，**修复过的 Windows 路径 bug**）。
- 行操作：下载（文件/目录 zip）、编辑、chmod（prompt 八进制）、chown（prompt uid:gid）、删除（`Dialog.confirm`；目录非空 409 → 二次确认递归）。
- 内置编辑器：行号（同步 scroll）、Tab 缩进、Ctrl+S 保存、未保存关闭提醒；保存 `POST /api/file`。

### `SearchPanel.vue`
- 引擎 Chip 勾选（从 `GET /api/search/stats` 的 engines）+ 本地库 Chip；搜索框 + 「搜索」「已收录」。
- 结果：`[本地]/[必应/百度/DuckDuckGo]` 标签 + 标题（点击预览）+ 摘要 + 打开原文/查看/收藏收录。
- 预览子面板：`POST /api/search/fetch`，标题 + 正文（等宽 pre-wrap）+ 收藏收录。
- 已收录库：`GET /api/search/catalog` 列表，打开原文/删除（确认）；`POST /api/search/delete`。

### `AuditPanel.vue`
- 状态文本 + 扫描目录 Input + 「开始审计」/「刷新」；`POST /api/audit/start` → 1.5s 轮询 `status`，完成拉 `result`。
- 摘要 chips（严重/高/中/低）；级别筛选 Select；问题列表（Checkbox 勾选 + 全选 + 计数）；severity→Badge 颜色。
- 「生成修复预览」→ `POST /api/audit/fix` → 弹窗逐文件 `DiffView` → 「确认修复」→ `?confirm=true`。
- 监听 `state.auditTick`（WS `audit_log` 广播）自动刷新。

### `SettingsDialog.vue`
- 手写 Modal（Teleport）；Tabs：基础 / 厂商 / 高级。
- `watch(settingsOpen)` 打开时深拷贝 `state.settings` 到 `local`；**`!state.settings` 显示「正在加载设置」并禁用保存**。
- 基础：model / api_key(password) / base_url / temperature / max_tokens / max_iterations / streaming / auto_allow / subagents / compaction / title_gen / cache_enabled（Switch 用 `:model-value="!!x"` + `@update` 避免可选布尔类型问题）。
- 厂商：providers 行（name/type/base_url/api_key/model 内联编辑 + 激活 + 获取模型 + 删除）+ 新增厂商表单；`fetchModels` 基于 `state.settings` 快照**临时激活目标厂商**再 `GET /api/models`（不影响未提交修改）。
- 高级：数值/开关/逗号列表/tool_rules 行编辑/mcp_servers JSON。
- `buildSettings()`：深拷贝→数值归一（`Number(x)||0`）→ tool_rules 组装 → 逗号列表 `splitList` → mcp `JSON.parse`（失败拦截）→ 激活厂商镜像回写；`save()` 前置守卫（settings 已加载 + WS connected）。

### `DiffView.vue`
- diff 文本按行分类：`---/+++/diff/index` 灰、`@@` 天蓝、`+` 绿、`-` 红、其他默认；`bg-zinc-950` 代码块。

## 重要交互细节（易踩坑）
1. **fuxsto 组件必须 import**（每个用到的 SFC 顶部）。
2. **Switch 可选布尔**：`v-model="local.x"`（x:boolean|undefined）会类型报错 → 用 `:model-value="!!local.x"` + `@update:model-value="local.x = !!$event"`。
3. **Select 同时写 v-model 与 @update 会重复绑定** → 统一用 `:model-value` + `@update`。
4. **文件面板路径**：后端返回 Windows 反斜杠路径；内部用正斜杠归一处理（面包屑/上级）。
5. **编辑器键盘**：Tab 插入两空格需 `preventDefault`；Ctrl+S 拦截浏览器保存。
