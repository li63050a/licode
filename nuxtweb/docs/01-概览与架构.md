# 01 · 概览与架构

## 1. 项目是什么

**licode** 是一个本地自托管的 AI 编程助手：一个 Go 二进制提供 Web 服务、LLM Agent、工具执行、WASM 插件、联网搜索、代码审计等能力。

本仓库（`D:\code\licode`）在此之上维护一个**独立的新前端 `nuxtweb/`**（Nuxt 3）：

- 支持两种形态：**Node 代理/中继形态**（dev / `.output`，不改后端）与 **静态内嵌形态**（`npm run generate` → `dist/` → `go:embed` 进 Go 二进制，替代后端旧界面）。
- 静态内嵌形态下，新前端通过**同源直连**访问后端 REST API 与 WebSocket，无代理、无 CORS；旧界面（`internal/web` 的 HTMX + Go 模板）被替代，模板代码仍保留在仓库作为兜底。
- 功能与旧界面**完全对齐**并额外补齐（搜索面板、下载、多文件上传、完善的设置表单等）。

> 静态内嵌的机制、构建与验证见 [13-静态生成与内嵌Go后端](13-静态生成与内嵌Go后端.md)。

## 2. 三层架构

| 层 | 技术 | 位置 | 职责 | 部署形态 |
| --- | --- | --- | --- | --- |
| 后端 | Go 1.22（gorilla/websocket、wazero、fsnotify、cobra） | `cmd/`、`internal/` | HTTP+WS 服务、LLM Agent、工具、插件、搜索、审计 | 单二进制（CGO_ENABLED=0，47 平台） |

## 3. 通信拓扑

**形态 A：Node 代理/中继（dev / `.output`）**

```
浏览器
  │  http://localhost:3000
  ▼
Nuxt 前端（nuxtweb，Node 进程）
  ├─ /api/*        ──► devProxy(dev) / routeRules(prod) ──► Go 后端 :8080
  ├─ /login 提交    ──► server/routes/signin.post.ts（http.request，读 302 cookie）─► 后端 /login
  └─ /ws (升级)     ──► crossws 中继 server/routes/ws.get.ts（透传 cookie + 消息排队）─► 后端 /ws
```

要点：

1. **浏览器只与前端 origin（localhost:3000）通信**，登录 cookie 也设在前端 origin 上，由中继转发到后端 origin（默认 127.0.0.1:8080）。
2. 后端从不直接服务前端页面；两个进程完全解耦，可分别部署/重启。
3. `/api/**` 代理是**通配**的：后端新增 REST 端点通常不需要改前端网络层。
4. `/ws` 不是简单 HTTP 代理（见 [08-前端-架构与对接](08-前端-架构与对接.md)），走 crossws 中继。

**形态 B：静态内嵌（`go:embed`，单二进制）**

```
浏览器
  │  http://<host>:8080/（同一 origin）
  ▼
Go 二进制（内置 Nuxt 静态产物 internal/web/nuxt）
  ├─ /          ──► serve index.html（SPA，前端路由接管 /login 等）
  ├─ /_nuxt/*   ──► 静态产物（不要求认证，登录页也依赖）
  ├─ /login     ──► 原生 form POST（302 + Set-Cookie 由浏览器处理）→ 前端错误经 ?error=1
  ├─ /api/*     ──► 后端 REST（同源直连，无代理）
  └─ /ws        ──► 后端 WebSocket（同源直连，无中继）
```

要点：

1. **页面、API、WS 同源**：`useApi` 相对路径 fetch 与 `useLicode` 的 `location.host` 直接命中后端，无 CORS、无代理。
2. 登录走**原生表单** `POST /login`（静态产物不含 `/signin` 中继），浏览器自动跟随 302 保存 cookie。
3. 构造与验证细节见 [13-静态生成与内嵌Go后端](13-静态生成与内嵌Go后端.md)。

## 6. 功能对齐清单（前端 vs 后端能力）

| 功能 | 后端能力 | 前端入口 |
| --- | --- | --- |
| 聊天（流式/工具块/权限询问/中断/分支） | WS `message` + 事件流 | ChatArea |
| 会话管理 | WS session_* | SidebarNav |
| 设置（含厂商管理、获取模型） | WS settings_get/set、REST /api/models | SettingsDialog |
| 文件浏览/编辑/新建/删除/chmod/chown | REST /api/files 等 | FilesPanel |
| 文件上传（多选/当前目录）/下载（目录 zip） | REST /api/upload、/api/download | FilesPanel |
| 联网搜索/网页预览/收录库 | REST /api/search/*、WS 工具 WebSearch/WebFetch | SearchPanel |
| 代码审计/一键修复 | REST /api/audit/*、WS audit_log | AuditPanel |
| 信息/统计/备份 | WS stats、REST /api/version、/api/export、/api/import | InfoPanel |
| 主题/连接状态 | -（前端本地） | TopBar / ConnectionBanner |
