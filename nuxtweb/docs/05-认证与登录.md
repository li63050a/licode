# 05 · 认证与登录

> 实现：`cmd/auth.go`。静态内嵌形态下页面与后端**同源**，cookie 由浏览器自动携带，无需任何中继。

## 1. 启用条件
- 设置了密码（`--password` 或 `LICODE_PASSWORD`）→ 登录启用。
- 用户名默认 `licode`（`--username` / `LICODE_USERNAME` 可改）。
- 未启用：所有页面/API 直接放行；`GET /login` 302 → `/`。

## 2. Cookie 与会话令牌（`cmd/auth.go`）

| 项 | 值 |
| --- | --- |
| Cookie 名 | `licode_auth` |
| 属性 | `HttpOnly; SameSite=Lax; Path=/; Max-Age=604800`（7 天） |
| Token 结构 | `base64url(用户名 + "." + 过期Unix时间戳 + "." + hex(hmac-sha256(secret, "user.exp")))` |
| 密钥 | `~/.licode/session.key`（持久化 → 后端重启后 cookie 仍有效） |
| CSRF cookie | `licode_csrf`（生成于登录页，`SameSite=Strict`；**validateCSRF 存在但未强制**） |

校验逻辑（`require`）：
- 无 `licode_auth` 或校验失败 → 未认证。
- 未认证且请求带 `Accept: application/json`（或路径 `/ws`）→ **401 纯文本**；否则 `302 → /login`。
- `/_nuxt/*` 静态资源**不要求认证**（登录页也是 SPA，需要加载这些资源）。

## 3. 后端登录流程（`handleLogin`）
- `POST /login`：表单 `username` + `password`。
  - 成功 → `setSession`（写 `licode_auth` cookie）+ `302 → /`。
  - 失败 → `302 → /login?error=1`（**无 cookie**）。
- `GET /login`：返回静态内嵌的 Nuxt 登录页 `login/index.html`（SPA）。

## 4. 静态内嵌登录链路（原生 form，关键：302 上的 cookie）

```
浏览器 /login 页
  → 原生 <form action="/login" method="post">（login.vue，username/password 由 v-model 同步到 hidden input）
     └─ 浏览器原生跟随 302，自动保存 Set-Cookie: licode_auth
        ├─ 成功 → 302 / → Nuxt 主页 → 前端 /api/auth 确认后 connect()
        └─ 失败 → 302 /login?error=1 → login.vue 读 route.query.error 显示「用户名或密码错误」
```

> **为什么必须原生 form，不能用 `$fetch`/`fetch` 跟随重定向**：fetch 跟随 302 后只能看到最终响应头，302 上的 `Set-Cookie` 会丢失 → 登录「成功」但浏览器没有 cookie → `/api` 401、WS 401，后端日志永远没有「客户端已连接」。原生表单提交由浏览器处理重定向与 cookie，天然避开此坑。

`pages/login.vue` 要点：
```vue
<form action="/login" method="post">
  <input type="hidden" name="username" :value="username" />
  <input type="hidden" name="password" :value="password" />
  ...
</form>
```

## 5. WS 认证
- 静态内嵌形态下页面与后端**同源**：浏览器升级 `ws://<host>/ws` 自动携带 `licode_auth` cookie → 后端直接认证通过。
- 后端 WS `CheckOrigin` 放行（无需前端处理 CORS）。

## 6. 前端登录守卫（`pages/index.vue` onMounted）
```
GET /api/auth
 ├─ 失败（后端不可达）→ 继续渲染界面，靠 ConnectionBanner + WS 自动重连
 ├─ enabled=false → 直接 connect()（无需登录）
 └─ enabled=true → GET /api/version
      ├─ 200 → connect()（已登录）
      └─ 401 → navigateTo('/login')
```
- 登录页 `login.vue`：用户名**预填 `licode`**；原生 form 提交（见 §4）；密码错误经 `?error=1` 显示红色错误框。

## 7. 同源说明
- 静态内嵌形态下页面、API、WS 同一 origin，登录 cookie 直接落在后端 origin，浏览器自动携带，**无跨域、无代理、无中继**。
